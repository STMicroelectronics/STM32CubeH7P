Example: st7315_display_image

Example version: 2.0.0

This example demonstrates how to display a monochrome bitmap image using the ST7315 128x64 OLED display controller, used in OLED modules such as the GJX-2864TSWBG09.

1. Detailed scenario

Initialization phase: At main program start, the mx_system_init() function is called. It initializes the peripherals, nonvolatile memory (such as flash memory, NVM, or external memories), MPU regions (if applicable), the system clock, and the SysTick.

Step 1: Initializes the ST7315 instance.

Step 2: Renders the ST logo monochrome bitmap into the frame buffer and transfers it to the display.

End of example: A static image is displayed on the screen. You can verify that the example runs properly via the status LED and the ExecStatus variable.

If you enable USE_TRACE, you can follow these execution steps in the terminal logs:

[INFO] Step 1: Device initialization COMPLETED.

[INFO] Step 2: ST Logo Displayed.

2. Example configuration

GPIO: OLED Part Driver Control Pins

The OLED part driver manages control signals through specific GPIO pins. These pins should be configured as follows:

  • Chip Select (CS): Configured as an output pin with push-pull.
  • Data/Command (DC): Configured as an output pin with push-pull, driven LOW for command mode and HIGH for data mode.
  • Reset (RST): Configured as an output pin with push-pull.

SPI: OLED Part Driver Configuration

The OLED part driver is controlled through the SPI peripheral configured as follows:

  • Mode: Controller
  • Direction: 1-line transmit only
  • Data size: 8 bits
  • Clock polarity: Low (CPOL = 0)
  • Clock phase: First edge (CPHA = 0)
  • NSS: Software controlled
  • Baud rate prescaler: /32, yielding 6.25 MHz at the 200 MHz SPI input clock used on the STM32H7P5I-DK, which stays within the 10 MHz ST7315 maximum

4. Troubleshooting

Here are the points of attention for this specific example:

SPI clock: If the image is displayed abnormally or corrupted, ensure that the SPI clock frequency does not exceed the maximum SPI clock frequency supported by the ST7315. The ST7315 datasheet specifies a minimum serial clock period of 100 ns, which corresponds to a maximum SPI clock frequency of 10 MHz for both 4-wire and 3-wire SPI modes. The default configuration uses a /32 prescaler (6.25 MHz at 200 MHz SPI input clock), which provides safe margin. If porting to a different board or clock tree, recompute the prescaler to keep the SPI clock at or below 10 MHz.

Frame buffer layout: The ST7315 uses a page-based frame buffer where each byte represents 8 vertically stacked pixels. The total frame buffer size is 128 x 8 bytes (1024 bytes) for a 128x64 monochrome display.
